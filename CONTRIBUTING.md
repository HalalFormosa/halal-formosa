## Sign off your commits (DCO)

Add a sign-off line to every commit to confirm the above:

```bash
git commit -s -m "feat: your change"
```

This appends `Signed-off-by: Your Name <you@example.com>`. Pull requests without
sign-offs may be asked to amend before merging.

## How to contribute

1. Fork the repository and create a branch: `git checkout -b feature/your-change`.
2. Copy `.env.example` and fill in your own keys. Never commit `.env` files or secrets.
3. Keep changes focused. Follow the existing code style, and run the tests (`npm test`).
4. Open a pull request describing what changed and why.
