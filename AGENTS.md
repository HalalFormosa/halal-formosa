# Agent instructions

## Brand and design
Before creating or changing anything visual or user-facing (UI, copy, marketing carousels, videos, emails), follow [docs/brand-guidelines.md](docs/brand-guidelines.md). See also [DESIGNS.md](DESIGNS.md).

Key rules, in short:
- The name is "Halal Formosa". Verdict labels are exactly Halal, Muslim-friendly, Syubhah and Haram, and each is always shown with its text, never by colour alone.
- Never claim the app certifies halal status.
- Don't use admin screenshots or real user data in public material.
- Anything the guidelines list under "Open items" is undecided. Ask the owner instead of inventing it.
