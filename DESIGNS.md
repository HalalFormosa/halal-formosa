# Designs

Source of truth for brand, voice and visual rules: [docs/brand-guidelines.md](docs/brand-guidelines.md). Read it before making any UI, marketing, carousel, video or email design. Don't copy its rules here; update that file instead.

In-app tokens live in `src/theme/variables.css` ("Modern Minimal" design system). The brand orange is `--ion-color-carrot`. The status colours (success, primary, warning, danger) are only for Halal, Muslim-friendly, Syubhah and Haram labels, never for decoration.
